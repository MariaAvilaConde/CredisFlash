ℹ️ ¿Cómo funciona?

  • Selecciona la red y el faucet que quieres consultar.
  • Si tienes la wallet conectada, la red activa se selecciona automáticamente.
  • La app escanea los últimos bloques buscando transacciones salientes del faucet.
  • Cada fila representa una solicitud atendida — alguien recibió tokens del faucet.
  • Puedes filtrar por dirección destino para ver si una dirección recibió fondos.
  • No se necesita ningún login ni wallet conectada.
