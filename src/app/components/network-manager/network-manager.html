ℹ️ ¿Cómo funciona?

  • Cambiar red: Si la red ya está en MetaMask, cambia directamente. Si no existe, se añade automáticamente.
  • Desconectar: Revoca los permisos de la wallet en la red seleccionada.
  • Historial: Las redes con API de explorador cargan el historial al instante. Las demás usan escaneo RPC (más lento).
  • Red custom: Puedes añadir cualquier red EVM compatible rellenando el formulario.
